# 🚀 БЫСТРЫЙ СТАРТ

## 1️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

## 2️⃣ Конфигурация (ВАЖНО!)

Откройте `config.py` и замените:

```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"  # Получить у @BotFather
ADMIN_ID = 123456789                # Ваш ID (узнать у @userinfobot)
CHANNEL_ID = -1001234567890         # ID канала (узнать у @userinfobot)
CHANNEL_LINK = "https://t.me/your_channel"  # Ссылка на канал
```

## 3️⃣ Запуск бота

```bash
python main.py
```

Если всё работает, вы увидите:
```
✅ Бот запущен!
Полинг сообщений начал работу
```

## 4️⃣ Использование

### Для клиентов:
- Отправьте `/start` в боте
- Пройдите проверку подписки на канал
- Нажмите "📅 Записаться на приём"
- Выберите дату, время, введите имя и номер телефона

### Для администратора:
- Отправьте `/admin` в боте
- Добавьте рабочие дни
- Управляйте временными слотами
- Просматривайте и отменяйте записи
