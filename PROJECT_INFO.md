## 🔑 Ключевые переменные в config.py

| Переменная | Описание | Пример |
|-----------|---------|--------|
| `BOT_TOKEN` | Токен от BotFather | `"7123456789:ABCdef..."` |  
| `ADMIN_ID` | Ваш ID Telegram | `123456789` |
| `CHANNEL_ID` | ID для отправки расписания | `-1001234567890` |
| `CHANNEL_LINK` | Ссылка на канал для подписки | `"https://t.me/mychannel"` |
| `WORK_START_HOUR` | Начало рабочего дня | `10` |
| `WORK_END_HOUR` | Конец рабочего дня | `19` |
| `SLOT_DURATION` | Длительность слота (минуты) | `60` |
| `WORK_DAYS` | Рабочие дни (0=Пн, 6=Вс) | `[0, 1, 2, 3, 4, 5]` |

## 🗄️ Структура БД

### Таблица `working_days`
- `id` - ID дня
- `date` - Дата (YYYY-MM-DD)
- `is_closed` - Закрыт ли день (0/1)
- `created_at` - Дата создания

### Таблица `time_slots`
- `id` - ID слота
- `date` - Дата, к которой относится слот
- `time` - Время слота (HH:MM)
- `is_booked` - Забронирован ли (0/1)

### Таблица `bookings`
- `id` - ID записи
- `user_id` - ID пользователя Telegram
- `date` - Дата записи
- `time` - Время записи
- `name` - Имя клиента
- `phone` - Номер телефона
- `created_at` - Дата создания

### Таблица `reminders`
- `id` - ID напоминания
- `booking_id` - Связь с записью
- `user_id` - ID пользователя
- `reminder_date` - Когда отправить напоминание
- `is_sent` - Отправлено ли (0/1)

## 🔔 Система напоминаний

- Напоминание отправляется **за 24 часа** до записи
- Использует **APScheduler**
- При отмене записи напоминание удаляется
- При перезагрузке бота напоминания восстанавливаются из БД
- Если запись менее чем за 24 часа, напоминание не создается

## 🛡️ Безопасность

- Проверка подписки на канал перед записью (обязательна)

- Каждый пользователь может иметь только одну активную запись

## 📝 Логирование

Все события логируются с форматом:
```
2024-03-15 14:30:45,123 - __main__ - INFO - База данных инициализирована
```

Уровни логирования:
- `INFO` - информационные сообщения
- `ERROR` - ошибки при выполнении операций
- `DEBUG` - отладочная информация (при необходимости)

## 🐛 Решение проблем

### Ошибка "ModuleNotFoundError"
```bash
pip install -r requirements.txt
```

### Бот не запускается
- Проверьте, что Python версии 3.9+
- Убедитесь в правильности BOT_TOKEN
- Проверьте консоль на ошибки

### Напоминания не работают
- Проверьте, что `APScheduler` установлен
- Убедитесь, что бот работает непрерывно
- Проверьте БД через `SELECT * FROM reminders`

### Админ не может получить доступ
- Проверьте, что правильно указан ADMIN_ID в config.py
- Используйте @userinfobot для получения вашего ID

## 📂 Где хранится БД

База данных автоматически создается в файле `nail_bot.db` в папке проекта.

Для просмотра записей используйте любой SQLite браузер или команду:
```bash
sqlite3 nail_bot.db
SELECT * FROM bookings;
```
