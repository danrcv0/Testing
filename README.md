# 📱 Telegram-бот для мастера по маникюру

Полнофункциональный бот для управления записями на маникюр с поддержкой админ-панели, напоминаниями и управлением расписанием.

## 🚀 Возможности

✅ **Для клиентов:**
- Просмотр доступных дней и времени на месяц вперёд
- Удобное бронирование через inline-календарь
- Автоматические напоминания за 24 часа до визита
- Возможность просмотра и отмены своей записи
- Просмотр прайсов и портфолио
- Обязательная проверка подписки на канал

✅ **Для администратора:**
- Добавление рабочих дней
- Управление временными слотами
- Просмотр расписания на выбранный день
- Отмена записей клиентов
- Закрытие/открытие дней
- Полная админ-панель с inline-кнопками

✅ **Технические особенности:**
- FSM (Finite State Machine) для управления состояниями
- SQLite база данных
- APScheduler для автоматических напоминаний
- Красивое HTML-форматирование сообщений
- Восстановление напоминаний при перезагрузке бота
- Полная обработка ошибок и логирование

## 📋 Требования

- Python 3.9+
- Telegram аккаунт
- Bot Token от BotFather

## ⚙️ Конфигурация

### 1. Получить Bot Token

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен
4. Скопируйте токен

### 2. Отредактировать config.py

Откройте файл `config.py` и замените значения:

```python
# Токен вашего бота
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"

# Ваш ID (узнайте в @userinfobot)
ADMIN_ID = 123456789

# ID канала для расписания (получите в @userinfobot)
# Если это группа, используйте отрицательное число
CHANNEL_ID = -1001234567890

# Ссылка на канал (для кнопки подписки)
CHANNEL_LINK = "https://t.me/your_channel"

# Ссылка на портфолио
PORTFOLIO_LINK = "https://ru.pinterest.com/crystalwithluv/_created/"
```

### 3. Узнать свой ID и ID канала

- Отправьте сообщение боту **@userinfobot**
- Он вернёт ваш ID
- Добавьте бота в канал и отправьте любое сообщение
- Используйте **@userinfobot** снова - он покажет ID канала

## 📖 Использование

### Для клиентов

1. **Запустить бота:** отправить `/start`
2. **Подписаться на канал:** если вы не подписаны, нажимать кнопку "Подписаться" и потом "Проверить подписку"
3. **Записаться:** нажать "📅 Записаться на приём"
4. **Выбрать дату:** кликнуть на дату в календаре
5. **Выбрать время:** кликнуть на свободное время
6. **Ввести данные:** указать имя и номер телефона
7. **Подтвердить:** нажать "✅ Подтвердить"

### Для администратора

1. **Запустить админ-панель:** отправить `/admin`
2. **Добавить рабочий день:**
   - Нажать "➕ Добавить рабочий день"
   - Ввести дату в формате `2024-03-15`
   - День будет добавлен с 9 временными слотами
3. **Управлять слотами:**
   - Нажать "⏰ Добавить временные слоты"
   - Выбрать дату
   - Ввести слоты: `10:00 11:00 12:00 13:00`
4. **Просмотреть расписание:**
   - Нажать "🔍 Просмотр расписания"
   - Выбрать дату
   - Видеть все записи (можно отменить запись, кликнув на неё)
5. **Закрыть день:** нажать "❌ Закрыть день" и выбрать дату

## 🐛 Решение проблем

### "ModuleNotFoundError: No module named 'aiogram'"

**Решение:** установите зависимости командой:
```bash
pip install -r requirements.txt
```

### "InvalidQueryID" ошибка при нажимании кнопок

**Решение:** убедитесь, что используется свежая версия aiogram:
```bash
pip install --upgrade aiogram
```

### Бот не работает

**Проверьте:**
1. Правильно ли введён BOT_TOKEN в config.py
2. Запущен ли бот: должно быть сообщение "Полинг сообщений начал работу"
3. Нет ли ошибок в консоли

## 📝 Куки и переменные окружения (опционально)

Для скрытия токена можно использовать переменные окружения:

### Создайте файл `.env`

```
BOT_TOKEN=your_token_here
ADMIN_ID=123456789
CHANNEL_ID=-1001234567890
CHANNEL_LINK=https://t.me/your_channel
```

### Обновите config.py

```python
from dotenv import load_dotenv
import os

load_dotenv()

BOT_TOKEN = os.getenv("BOT_TOKEN", "YOUR_BOT_TOKEN_HERE")
ADMIN_ID = int(os.getenv("ADMIN_ID", "123456789"))
CHANNEL_ID = int(os.getenv("CHANNEL_ID", "-1001234567890"))
CHANNEL_LINK = os.getenv("CHANNEL_LINK", "https://t.me/your_channel")
```
